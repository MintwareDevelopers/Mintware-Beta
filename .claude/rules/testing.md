# Testing

TypeScript tests use Vitest. Forge contract tests are under `contracts-v4/test/`. The generated Vitest suite list
below is derived from source; do not hand-edit it.

## Requested verification commands

- `pnpm exec tsc --noEmit -p .`
- `pnpm exec vitest run`
- `pnpm exec eslint <edited .ts/.tsx files>`

Do not interpret historical test counts in archived reports as current results. Testnet deployment does not mean
contracts are audited; external audit gates real value.

## MarketEngine and payment contract suites

`contracts-v4/test/payments/`. Current source names and test inventory are discoverable with `rg --files
